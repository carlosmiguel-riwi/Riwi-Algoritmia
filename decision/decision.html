Introducción a la algoritmia y pensamiento computacional:

Algoritmo de decisión en PSeInt para calcular el descuento y el costo de envío de una compra, con tabla de decisión y pruebas de escritorio que incluyen los casos borde.

Descuentos y envío de una compra.

El algoritmo valida que el monto no sea negativo y, según el estado VIP del cliente y si la compra alcanza los 100, determina el descuento y el costo de envío. Las compras de 100 o más no pagan envío. Para ejecutar el algoritmo, el monto debe ingresarse como número y la condición VIP como Verdadero o Falso.

Algoritmo en PSeInt:

Algoritmo SistemaTienda
    Definir monto, descuento, costoEnvio, total Como Real
    Definir esVIP Como Logico

    Escribir "Ingrese el monto de la compra:"
    Leer monto

    Si monto < 0 Entonces
        Escribir "Error: el monto de la compra no puede ser negativo."
    SiNo
        Escribir "¿El cliente es VIP? (Verdadero/Falso):"
        Leer esVIP

        descuento <- 0
        costoEnvio <- 10

        Si esVIP Entonces
            Si monto >= 100 Entonces
                descuento <- monto * 0.20
                costoEnvio <- 0
            SiNo
                descuento <- monto * 0.10
            FinSi
        SiNo
            Si monto >= 100 Entonces
                descuento <- monto * 0.05
                costoEnvio <- 0
            FinSi
        FinSi

        total <- monto - descuento + costoEnvio
        Escribir "Monto ingresado: ", monto
        Escribir "Descuento aplicado: ", descuento
        Escribir "Costo de envio: ", costoEnvio
        Escribir "Total a pagar: ", total
    FinSi
FinAlgoritmo

Diagrama de flujo:

Tabla de decisión:

Cliente VIP Monto de compra Descuento Costo de envío
No Menor que 100 0 % 10
No 100 o más 5 % 0
Sí Menor que 100 10 % 10
Sí 100 o más 20 % 0

Si el monto es menor que cero, el algoritmo informa el error y no calcula el descuento ni el total.

Prueba de escritorio (incluye casos borde):
