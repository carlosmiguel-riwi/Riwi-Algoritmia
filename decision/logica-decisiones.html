Validar registro.

Regla: se puede registrar quien tiene 14 años o más Y acepta los términos. La respuesta se pasa a mayúsculas antes de comparar para que «s» y «S» valgan igual.

Tabla de verdad:

edad >= 14AceptaResultado
VerdaderoVerdaderoRegistro exitoso
VerdaderoFalsoNo puedes registrarte
FalsoVerdaderoNo puedes registrarte
FalsoFalsoNo puedes registrarte

Algoritmo en PSeInt:

Algoritmo ValidarRegistro
    Definir edad Como Entero
    Definir respuesta Como Caracter
    Escribir "Ingrese su edad:"
    Leer edad
    Escribir "¿Aceptas los términos? (S/N):"
    Leer respuesta
    respuesta <- Mayusculas(respuesta)
    Si edad >= 14 Y respuesta = "S" Entonces
        Escribir "Registro exitoso"
    SiNo
        Escribir "No puedes registrarte"
    FinSi
FinAlgoritmo

Edad válida y propinas corregida.

Negar con De Morgan: la edad es válida si edad >= 0 Y edad <= 120; es inválida si edad < 0 O edad > 120 (al negar, la Y cambia a O). Además, la calculadora de propinas ahora evita la división por cero.

Edad¿edad < 0 O edad > 120?Resultado
-1SíInválida
0NoVálida (borde)
120NoVálida (borde)
121SíInválida

Decisión agregada a la calculadora de propinas:

Si personas <= 0 Entonces
    Escribir "El número de personas debe ser mayor que cero"
SiNo
    propina <- cuenta * porcentaje / 100
    total <- cuenta + propina
    Escribir "Cada persona paga: ", total / personas
FinSi

Parqueadero.

Carro: $4.000 por hora o fracción; moto: $2.000. Los primeros 15 minutos son gratis, el máximo diario es $30.000 y con factura del centro comercial se paga la mitad (después del tope). Tipo inválido o minutos negativos es error.

Tabla de decisión:

ReglaTipoMinutosFacturaResultado
R1CualquieraMenos de 0CualquieraError: minutos negativos
R2Ni 1 ni 20 o másCualquieraError: tipo no válido
R3Carro o motoDe 0 a 15CualquieraGratis
R4Carro o motoMás de 15NoHoras × tarifa, máximo $30.000
R5Carro o motoMás de 15SíLo de R4 dividido entre 2

Algoritmo en PSeInt:

Algoritmo Parqueadero
    Definir tipo, minutos, horas Como Entero
    Definir tarifa, valor Como Real
    Definir factura Como Caracter
    Escribir "Tipo de vehículo (1 = Carro, 2 = Moto):"
    Leer tipo
    Escribir "Minutos de estadía:"
    Leer minutos
    Si minutos < 0 Entonces
        Escribir "Error: minutos negativos"
    SiNo
        Segun tipo Hacer
            1: tarifa <- 4000
            2: tarifa <- 2000
            De Otro Modo: tarifa <- 0
        FinSegun
        Si tarifa = 0 Entonces
            Escribir "Error: tipo no válido"
        SiNo
            Si minutos <= 15 Entonces
                valor <- 0
            SiNo
                horas <- trunc((minutos + 59) / 60)
                valor <- horas * tarifa
                Si valor > 30000 Entonces
                    valor <- 30000
                FinSi
                Escribir "¿Tiene factura del centro comercial? (S/N):"
                Leer factura
                Si Mayusculas(factura) = "S" Entonces
                    valor <- valor / 2
                FinSi
            FinSi
            Escribir "Valor a pagar: $", valor
        FinSi
    FinSi
FinAlgoritmo

Semáforo de inventario.

Menos de 0 unidades: error; 0: rojo, agotado; de 1 a 10: amarillo, hay que pedir; más de 10: verde, todo bien.

Algoritmo en PSeInt:

Algoritmo Semaforo
    Definir unidades Como Entero
    Escribir "Unidades en inventario:"
    Leer unidades
    Si unidades < 0 Entonces
        Escribir "Error: unidades negativas"
    SiNo
        Si unidades = 0 Entonces
            Escribir "ROJO: agotado"
        SiNo
            Si unidades <= 10 Entonces
                Escribir "AMARILLO: hay que pedir"
            SiNo
                Escribir "VERDE: todo bien"
            FinSi
        FinSi
    FinSi
FinAlgoritmo

Año bisiesto.

Un año es bisiesto si es divisible entre 4 y no entre 100, o si es divisible entre 400. Los paréntesis son necesarios porque la Y se evalúa antes que la O.

Algoritmo en PSeInt:

Algoritmo Bisiesto
    Definir anio Como Entero
    Escribir "Ingrese un año:"
    Leer anio
    Si (anio MOD 4 = 0 Y anio MOD 100 <> 0) O anio MOD 400 = 0 Entonces
        Escribir "El año ", anio, " es bisiesto"
    SiNo
        Escribir "El año ", anio, " no es bisiesto"
    FinSi
FinAlgoritmo
