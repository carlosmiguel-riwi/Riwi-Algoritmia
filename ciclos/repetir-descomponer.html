Actividad repetir y descomponer.

Introducción a la algoritmia y pensamiento computacional:

Programas de la sesión 3 en PSeInt: ciclos con patrones (centinela, contador, acumulador, bandera, máximo y mínimo), ciclos anidados y descomposición en SubProcesos, con tablas de traza.

Cajero del PIN.

Tres intentos para escribir el PIN; si se fallan los tres, la tarjeta se bloquea. El ciclo debe parar si se acierta O si se acabaron los intentos (con Y nunca terminaría). Usa tres patrones: contador, bandera y límite de intentos. El PIN 1234 es un ejemplo.

Algoritmo en PSeInt:

Algoritmo CajeroPIN
    Definir pinCorrecto, pin, intentos Como Entero
    Definir acceso Como Logico
    pinCorrecto <- 1234
    intentos <- 0
    acceso <- Falso
    Repetir
        Escribir "Ingrese su PIN:"
        Leer pin
        intentos <- intentos + 1
        Si pin = pinCorrecto Entonces
            acceso <- Verdadero
        FinSi
    Hasta Que acceso O intentos = 3
    Si acceso Entonces
        Escribir "Acceso concedido"
    SiNo
        Escribir "Tarjeta bloqueada"
    FinSi
FinAlgoritmo

Cajero del parqueadero.

No se sabe cuántos carros llegan: se cobra uno por uno y el 0 es el centinela que cierra la caja. Se lee el primer valor antes del ciclo y de nuevo dentro de él (la actualización). Contador y acumulador arrancan en 0 antes del ciclo.

Algoritmo en PSeInt:

Algoritmo CajeroParqueadero
    Definir valor, total Como Real
    Definir carros Como Entero
    total <- 0
    carros <- 0
    Escribir "Valor cobrado (0 para cerrar la caja):"
    Leer valor
    Mientras valor <> 0 Hacer
        total <- total + valor
        carros <- carros + 1
        Escribir "Valor cobrado (0 para cerrar la caja):"
        Leer valor
    FinMientras
    Escribir "Carros atendidos: ", carros
    Escribir "Total recaudado: $", total
FinAlgoritmo

Calificaciones.

Con un solo ciclo Para se calcula el promedio, los aprobados (3 o más), la nota más alta, la más baja y si alguien perdió. El mayor arranca en 0 y el menor en 5 para que la primera nota siempre los reemplace.

Algoritmo en PSeInt:

Algoritmo Calificaciones
    Definir i, aprobados Como Entero
    Definir nota, suma, mayor, menor, promedio Como Real
    Definir alguienPerdio Como Logico
    suma <- 0
    aprobados <- 0
    mayor <- 0
    menor <- 5
    alguienPerdio <- Falso
    Para i <- 1 Hasta 5 Con Paso 1 Hacer
        Escribir "Nota del estudiante ", i, ":"
        Leer nota
        suma <- suma + nota
        Si nota >= 3 Entonces
            aprobados <- aprobados + 1
        SiNo
            alguienPerdio <- Verdadero
        FinSi
        Si nota > mayor Entonces
            mayor <- nota
        FinSi
        Si nota < menor Entonces
            menor <- nota
        FinSi
    FinPara
    promedio <- suma / 5
    Escribir "Promedio: ", promedio
    Escribir "Aprobados: ", aprobados
    Escribir "Nota más alta: ", mayor
    Escribir "Nota más baja: ", menor
    Si alguienPerdio Entonces
        Escribir "Hay estudiantes en refuerzo"
    FinSi
FinAlgoritmo

Pirámide.

Un ciclo dentro de otro: el externo recorre las filas y el interno dibuja primero los espacios (n - fila) y luego los asteriscos (2 * fila - 1, números impares). En la última fila el ciclo de espacios no da ninguna vuelta.

Algoritmo en PSeInt:

Algoritmo Piramide
    Definir n, fila, j Como Entero
    Escribir "Altura de la pirámide:"
    Leer n
    Para fila <- 1 Hasta n Con Paso 1 Hacer
        Para j <- 1 Hasta n - fila Con Paso 1 Hacer
            Escribir Sin Saltar " "
        FinPara
        Para j <- 1 Hasta 2 * fila - 1 Con Paso 1 Hacer
            Escribir Sin Saltar "*"
        FinPara
        Escribir ""
    FinPara
FinAlgoritmo

Factura del restaurante con SubProcesos.

El impuesto al consumo (8 %) y la propina (10 %) son el mismo problema, calcular un porcentaje, así que un solo SubProceso se usa dos veces.

Árbol de componentes:

  • FacturaRestaurante (algoritmo principal)
    • LeerPedido: lee los platos y devuelve el subtotal.
    • CalcularPorcentaje: devuelve base × porcentaje / 100 (se usa para impuesto y propina).
    • ImprimirFactura: muestra subtotal, impuesto, propina y total.

Algoritmo modular en PSeInt:

Algoritmo FacturaRestaurante
    Definir subtotal, impuesto, propina Como Real
    subtotal <- LeerPedido()
    impuesto <- CalcularPorcentaje(subtotal, 8)
    propina <- CalcularPorcentaje(subtotal, 10)
    ImprimirFactura(subtotal, impuesto, propina)
FinAlgoritmo

SubProceso subtotal <- LeerPedido()
    Definir subtotal, precio Como Real
    Definir n, i, cantidad Como Entero
    subtotal <- 0
    Escribir "¿Cuántos tipos de plato pidió?"
    Leer n
    Para i <- 1 Hasta n Con Paso 1 Hacer
        Escribir "Cantidad y precio del plato ", i, ":"
        Leer cantidad, precio
        subtotal <- subtotal + cantidad * precio
    FinPara
FinSubProceso

SubProceso resultado <- CalcularPorcentaje(base, porcentaje)
    Definir resultado Como Real
    resultado <- base * porcentaje / 100
FinSubProceso

SubProceso ImprimirFactura(subtotal, impuesto, propina)
    Escribir "----- FACTURA -----"
    Escribir "Subtotal: $", subtotal
    Escribir "Impuesto (8%): $", impuesto
    Escribir "Propina (10%): $", propina
    Escribir "Total a pagar: $", subtotal + impuesto + propina
FinSubProceso
